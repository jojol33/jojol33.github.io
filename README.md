# 💝 咪峰生日網頁 — 使用說明

只需要修改 **`config.js`** 這一個檔案（用記事本、VS Code 等文字編輯器打開即可），其他檔案都不用動。

> 小提醒：文字要放在 `"雙引號"` 裡，每一項的結尾要保留逗號 `,`。改完存檔，重新整理網頁就能看到結果。

---

## 🏠 首頁照片 → `home`

首頁最上面的拍立得照片：

```js
home: {
  photo: "images/home.jpg",          // 換照片就改這裡；留空 "" 不顯示
  caption: "全世界最可愛的咪峰 💗",   // 照片下面的字
  focus: "50% 46%",                  // 裁切焦點（左右% 上下%）
  zoom: 1.5                          // 放大倍數，1 = 原尺寸
},
```

照片找不到時會自動隱藏，不會壞掉。

## 0. 🎁 禮物月曆（解鎖時間）→ `schedule`、`games`

首頁是一個「禮物月曆」：7 個小遊戲每隔 10 天解鎖一個，最後生日當天解鎖告白信。
沒解鎖的禮物會顯示解鎖日期和倒數，點了也打不開。

```js
schedule: {
  start: "2026-10-24",   // 第 1 個遊戲解鎖日（台灣時間 00:00）
  intervalDays: 10       // 每隔幾天解鎖下一個
},
games: [
  { id: "quiz" },     // 第 1 個：10/24 關於我們的問答題
  { id: "hearts" },   // 第 2 個：11/3  接愛心
  { id: "memory" },   // 第 3 個：11/13 照片翻牌配對
  { id: "scratch" },  // 第 4 個：11/23 愛的刮刮樂
  { id: "puzzle" },   // 第 5 個：12/3  回憶拼圖
  { id: "words" },    // 第 6 個：12/13 情話拼字
  { id: "cake" }      // 第 7 個：12/23 吹蠟燭許願
],
```

- 解鎖日期會自動用 `start` + `intervalDays` 算出來。
- 想調換遊戲順序，直接把那幾行上下對調即可。
- 想指定某個遊戲的解鎖日：`{ id: "cake", unlock: "2026-12-20" }`
- 告白信的解鎖時間是 `birthday`（2027/1/2 00:00）。

**測試用網址（不要傳給咪峰！）**
- `?preview=1`：全部遊戲＋告白信一次解鎖
- `?now=2026-12-05`：假裝今天是某一天，看看月曆當天的樣子

## 1. ✍️ 告白信 → `letter`

```js
letter: {
  title: "給最愛的咪峰",                 // 信的標題
  paragraphs: [
    "第一段內容…",
    "第二段內容…",                         // 想寫幾段就加幾行
  ],
  signature: "永遠愛你的 ○○○"            // 署名
}
```

- 把「在這裡寫給咪峰的信…」換成你的內容。
- **每一段**用一組雙引號，段落之間用逗號隔開。
- 段落內如果想換行，可以寫 `\n`。
- 信件在 **2027/1/2 00:00（台灣時間）** 之前是鎖住的，時間到才會自動解鎖。

想先預覽解鎖後的樣子？在網址後面加上 `?preview=1`。

## 2. 💭 問答題 → `quiz`

目前 5 題都是標著【範例】的假題目，請換成你們的：

```js
{
  question: "我們第一次見面是在哪裡？",
  options: ["咖啡廳", "學校", "朋友聚會", "網路上"],
  answer: 2
},
```

- `answer` 是正確答案的「位置」，**從 0 開始數**：第 1 個選項 = `0`、第 2 個 = `1`、第 3 個 = `2`、第 4 個 = `3`。
- 題目數量可以增減，選項建議 2～4 個。

## 3. 📸 照片翻牌 → `photos`

需要 **6 張照片**（每張會出現兩次，共 12 張牌）。

1. 把照片放進 `images/` 資料夾，檔名建議用英文或數字，例如 `1.jpg`、`2.jpg`…
2. 在 `config.js` 裡把照片路徑填進去（把前面的 `//` 刪掉）：

```js
photos: [
  "images/1.jpg",
  "images/2.jpg",
  "images/3.jpg",
  "images/4.jpg",
  "images/5.jpg",
  "images/6.jpg",
],
```

- 照片建議接近直式（3:4），會自動裁切填滿卡片；檔案不要太大（每張 500KB 以內手機會比較順）。
- 還沒放照片、或照片數量不足 6 張時，缺的會自動用可愛表情符號代替。

## 4. 🎂 吹蠟燭許願 → `candles`、`wish`

```js
candles: 5,                       // 蠟燭數量（建議 3～8）
wish: {
  title: "生日快樂，咪峰！🎉",     // 吹完蠟燭後的標題
  message: "想對他說的話…"         // 吹完蠟燭後的祝福
}
```

- 點蠟燭就能吹熄；也可以按「🎤 用麥克風吹蠟燭」對著手機吹氣。
- 麥克風功能需要網站是 **https** 網址（例如放到 GitHub Pages、Netlify）才能用；直接打開檔案或拒絕權限時，會自動改成用手指點。

## 5. 💗 接愛心 → `hearts`

```js
hearts: {
  seconds: 30,          // 遊戲秒數
  target: 25,           // 幾分算過關（💗 +1、💖 +3、💔 −2）
  winMessage: "過關時顯示的話",
  loseMessage: "沒過關時顯示的話"
},
```

## 6. 🎟️ 刮刮樂 → `scratch`

每一張就是一張「應許券」，建議 3～4 張，刮開後他可以截圖找你兌換：

```js
scratch: {
  coupons: [
    { icon: "🎬", text: "應許券：陪你看一場電影" },
    { icon: "💆", text: "應許券：按摩 30 分鐘" },
  ],
  finishMessage: "全部刮完時顯示的話"
},
```

`icon` 可以換成任何表情符號。

## 7. 🧩 回憶拼圖 → `puzzle`

3×3 滑動拼圖。把一張照片（**建議正方形**）放進 `images/`，然後填上：

```js
puzzle: {
  image: "images/puzzle.jpg",   // 留空 "" 就會用可愛的數字拼圖
  finishMessage: "拼好時顯示的話"
},
```

## 8. 💬 情話拼字 → `words`

每一句會顯示提示（hint），他要按照順序點字拼出答案（phrase），裡面會混進幾個干擾字：

```js
words: {
  rounds: [
    { hint: "我最想對你說的三個字", phrase: "我愛你" },
    { hint: "我們第一次約會的地方", phrase: "淡水老街" },
  ],
  finishMessage: "全部完成時顯示的話"
},
```

`phrase` 建議 2～8 個字，不要放空白或標點符號。

---

## 其他

- 生日時間在 `birthday` 欄位（預設 `2027-01-02T00:00:00+08:00`），一般不用改。
- 網址加上 `#quiz`、`#hearts`、`#memory`、`#scratch`、`#puzzle`、`#words`、`#cake`、`#letter` 可直接打開某一頁（還沒解鎖的會自動回到月曆）。
- 他玩過的遊戲會在月曆上打勾 ✔（記錄存在他自己的手機瀏覽器裡）。
- 檔案結構：
  - `index.html` 主頁面
  - `config.js` ← **只要改這個**
  - `style.css` / `app.js` 樣式與程式
  - `images/` 放照片
